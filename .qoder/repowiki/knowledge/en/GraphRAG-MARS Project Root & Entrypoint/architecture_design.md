The root acts as the application surface: `main.py` registers an argparse-based CLI with four subcommands (`serve`, `ingest`, `graph`, `evaluate`) that lazily import from `src.api.app`, `src.rag.pipeline`, `src.graph.retriever`, and `src.evaluation.metrics` to keep startup lightweight. The FastAPI app is served via Uvicorn on port 8080 (with dev reload). `Dockerfile` builds a Python 3.11-slim backend image that installs `requirements.txt`, copies `src/`, and exposes 8080. `docker-compose.yml` orchestrates three services — a `neo4j:5-community` graph database (Bolt 7687, Browser 7474, APOC plugin), the `backend` container depending on Neo4j's healthcheck, and a `frontend` container built from `Dockerfile.frontend` on port 8501 — sharing a `./data` volume for documents and benchmarks. `.env.example` supplies the template for API keys consumed by Pydantic settings in `src/config.py`.
